# Home Server

My personal home server setup running Debian 13 on a Mac mini.
This is currently **Work in Progress**

## Hardware

- Model: Mac mini (Late 2012)
- Model Identifier: Macmini6,1
- CPU: Intel Core i5, 2.5 GHz, 2 cores / 4 threads
- RAM: 8GB
- Storage: 128GB
- Network: Wi-Fi

## OS
- OS: Debian 13
- Init: systemd
- Filesystem: btrfs

## Current Setup

- [x] Stable LAN IP configured
